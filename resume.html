Projects

Research Assistant, Max Planck Institute for Gravitational Physics (Albert Einstein Institute)

Developed a normalizing flow-based neural network model to optimize O4a continuous gravitational wave search strategies by predicting mismatch distributions between signals and search templates. The project addressed computational bottlenecks limiting detection sensitivity, focusing on parameter optimization for coherent integration time, template grid spacings, and refinement factors.

  • Achieved mean absolute error of 1% for directed searches and 0.8% for all-sky searches
  • 100x speedup in parameter estimation
  • Paper submitted to Physical Review D (under review).

Project Leader, National College Student Innovation Project, Sichuan University, China

Developed a black hole detection and parameter estimation model using simulated observations from space telescopes. The project involved black hole accretion disk simulation, telescope simulation, data processing, an ensemble deep learning model for both black hole detection and recognition, and final validation with the data from Hubble Space Telescope.
